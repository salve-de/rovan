# 勝ち負けから決める画面設計（オーナー決定 2026-09-29）

> 画面・文言・図を1つ作る前に、必ずこの表に照らす。どの「勝ち」にも効かない要素は作らない・残さない。

## 1. 何を達成するか

- **オーナーの収益 ＝ 地域の中小企業の社長に、月額の週次見守り（税込10,780円）を払い続けてもらうこと。**
- ユーザーが通る道は1本：サイトを見る → 社名などを入れて無料診断 → 結果を見て「負けている。でも取り返せる」 → 公開に同意・14日間無料で開始 → 支払い → 毎週の報告を見て続ける。
- 来る経路は「全部」（広告・SNSから初めて来る人、紹介・営業で渡されたURLから来る人）。初めての人には自分ごと化とヒヤッを、紹介の人にはすぐ診断できる入口を、どちらも最初の画面で満たす。

## 2. 勝ち（見た人がどう思い・感じ・動けばよいか）

| 場面 | 3秒で思ってほしいこと | 感情 | 勝ちの行動 |
|---|---|---|---|
| トップ | うちのお客さんも、AIに他の店を紹介されているかも。名前を入れるだけで分かるなら見てみよう | ヒヤッ＋気軽さ | 社名・Instagram・URLを入れて診断する |
| 診断結果 | 本当にライバルの名前が出て、うちは出ていない。でも大手と戦わなくても、うちの強みで取り返せる | 危機感→希望 | 公開に同意し、14日間無料で始める |
| 料金 | 人を雇うより安い。勝手に課金されない。いつでもやめられる | 安心 | 支払う |
| 毎週の報告 | ちゃんと見てくれている。数字が動いている | 手応え | 解約しない |

実績（お客さんの声・導入数）はまだ無いので作らない。**無料診断の結果そのものが証拠**になるよう、サイトは早く診断させることにすべてを使う。

## 3. 負け（こう思われたら終わり）

| 負け | 原因 |
|---|---|
| 何のサービスか分からず去る | 遠回しな見出し、長い文章 |
| 怪しい・AI詐欺っぽい | 誇大表現、保証に見える言い方、出典のない数字 |
| 難しそう・面倒そう | 専門用語（推薦候補・北極星・JSON-LD等）、設定が多く見える |
| うちには関係ない | 大企業向け・ホームページがある前提に見える |
| 結果を見て「で？」 | 何番目か・何をすればよいかが分からない |
| 高い | 価値が伝わる前に値段だけが出る |
| 無料で満足して終わる | 続ける理由（毎週変わる・放置すると取られる）が伝わらない |

## 4. 作るときのルール

1. 要素ごとに「誰が見る／3秒で何を思わせる／どんな感情／何をさせる（1つ）／何が負けか」を先に書く。書けない要素は作らない。
2. 一番言いたいことは全ページで1つ：**AIが、お客さんに他の店をすすめている。御社の名前を出させる。名前を入れるだけ・無料で分かる。**
3. 社長の言葉で書く。専門用語は画面に出さず、必要なら「くわしく」に畳む。
4. 作り物の図より、実際の画面（見本のお店・「見本」と明記）を見せる。
5. 保証しない・誇張しない（AGENTS.md）。数字には出典、国名は出典欄だけ。
