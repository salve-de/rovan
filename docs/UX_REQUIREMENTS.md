## 3. NN/g 10原則との対応

1. 状態の見える化 → 診断の進み具合、読み込み中の表示、見本・デモの表示
2. 利用者の言葉 → 社長の言葉で書く（CONVERSION_DESIGN.md ルール3）、用語「管理用リンク」に統一
3. 自由に戻れる → 公開停止・自動更新の停止・データ削除・解約の窓口
4. 一貫性 → 主ボタンは緑1色、ページ上部の構成を共通化
5. エラーの予防 → 入力は1つ、例文、ホームページなしでも進める道
6. 覚えさせない → 次の一手をボタンで示す、管理用リンクをメールでも送る
7. 柔軟さ → 社名・Instagram・URLのどれでも受け付ける
8. 最小限のデザイン → 1セクション1メッセージ（visual-design-taste）
9. エラーからの回復 → エラー画面に「もう一度試す」と別の道
10. ヘルプ → よくある質問、調べ方ページ、問い合わせ

## 4. まだ満たしていないもの

- D3 運営者情報・特定商取引法：販売者情報を登録すると自動で表示される（オーナー作業）

- F3 キーボード操作：全画面を通した確認は未実施
- 実際のAI接続での「名前だけで診断」：いまはデモ表示のみ（AIキー設定と診断処理の対応が必要）
