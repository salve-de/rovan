# Rovan デザインシステム（UI統一の基準）

対象ユーザーは ITに詳しくない地域中小企業の社長。**落ち着いた・信頼できる・一目で分かる**。派手さ・煽り・情報の壁は避ける。

## 1. 色（これ以外の色を直書きしない）
すべて `app/globals.css` の `:root` トークン経由で使う。TSX内の `#xxxxxx` 直書き禁止。

| 役割 | トークン | 値 |
|---|---|---|
| 文字（主） | `--text` | #0f172a |
| 文字（副） | `--text-muted` | #475569 |
| 文字（補足） | `--text-subtle` | #64748b |
| 背景 | `--bg` | #ffffff |
| 面（カード/セクション背景） | `--surface` | #f8fafc |
| 罫線 | `--border` | #e2e8f0 |
| 罫線（強） | `--border-strong` | #cbd5e1 |
| ブランド（主ボタン・強調・リンク） | `--brand` | #147a52 |
| ブランド（淡） | `--brand-soft` | #e5f5ed |
| 濃色（ヘッダー/濃色ボタン/フッター） | `--navy` | #102b43 |
| 注意（候補外・警告） | `--warn` / `--warn-soft` | #bd5a2f / #fff1e9 |
| 情報（中立の補足） | `--info` / `--info-soft` | #1769d3 / #eaf2fc |

意味の固定: 緑＝自社が候補に入った/良い変化、オレンジ＝候補外/注意、青＝中立の情報。赤は使わない。

## 2. 文字
- 見出し: h1 `--text-display` / h2 `--text-h2` / h3 18px。本文 15px、補足 13px、注記 12px。
- 太さは 400 / 700 の2段階（800・900 は使わない）。
- 英語の飾りラベル（"WORKFLOW" "AUDIT" "BILLING" 等）は使わない。見出しの上の小ラベルが必要なら日本語で短く。

## 3. 余白・形
- 余白は 8pt 系トークン `--sp-1`(8)〜`--sp-12`(96) のみ。
- 角丸: 小 6px（バッジ/入力）、中 10px（カード/ボタン）、大 16px（大きなパネル）。`--radius-sm/md/lg`。
- 影は `--shadow-sm`（カード）と `--shadow`（浮いたパネル）の2種のみ。

## 4. 共通部品（components/ui/*）— 新しく見た目を作らず、これを使う
- `Section`（ページ内の区切り。背景 plain/surface、見出し・リード文）
- `Card`（枠付きの箱）
- `Notice`（tone: info / warn / success。注意書き・状態表示）
- `Badge`（小さな状態ラベル。tone 同上）
- `Stat`（数値＋ラベル）
- ボタンは既存 `.button` + `button-primary`（ブランド緑）/ `button-dark`（紺）/ `button-secondary`（枠線）の3種のみ。

## 5. 文言
- 用語は3つに固定: **無料診断** / **AI推薦データ（公開ページ）** / **週次見守り**。Watch・Change Pack・パネル・Provider・台帳・看板 等の内部語をUIに出さない。
- 1画面1メッセージ。見出しで結論、本文は2〜3行。同じ説明・注意書きを繰り返さない。
- 保証・誇張しない（AGENTS.md 準拠）。「AIの推薦・順位・売上は保証しません」はフッター＋申込ボタン付近の1回に集約。
- `tests/copy-restoration.test.ts` の承認済み文言は変更・削除しない。

## 6. 画面の型
すべてのページ: ヘッダー → ページ見出し（何の画面か1行）→ 本文 → 次の行動（主ボタン1つ）→ フッター。行き止まり禁止。
